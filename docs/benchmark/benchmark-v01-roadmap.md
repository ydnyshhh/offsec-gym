# Benchmark roadmap after T0

**T0:** Detached versioned task contracts, eight-root registry, public/private separation, candidate difficulty schema, stage vocabulary, deterministic manifest generation, and static compiler qualification. Current readiness is partial for all eight roots; no model results or calibrated difficulty claims exist.

**T1:** Independently qualify runtime integrity, negative controls, public discovery, and same-run verifier-accepted outcomes for each existing task and both task modes. Retain explicit blockers where no public-only path is shown, especially for B2/B3.

**T2:** Add controlled single-factor range variations with regenerated oracles and public-path qualification. **T3/T4:** Build separately reviewed synthetic collaboration/search and provenance/configuration families. **T5:** Freeze harness compatibility, calibration sample, costs, model identities, uncertainty method, and held-out split before any separately authorized model study.

Development instances may debug generators; calibration instances estimate difficulty; held-out instances assess generalization. Semantic templates must stay grouped across splits. A private seed does not erase contamination from public root mechanisms. No task in this T0 artifact is advertised as a calibrated leaderboard item.
