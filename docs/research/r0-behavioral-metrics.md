# R0 offline behavioral metrics

`research_ops/benchmark_r0_analyze.py --input DIR --output .offsecgym/research/r0/analysis` reads retained `*.metadata.json`, `*.events.jsonl`, and `*.evaluation.json` files. An optional private `*.oracle.json` enables independent score replay; absence is reported as unknown. It never starts Docker or makes network/provider calls. A retained trace must declare model-run provenance, contain a model-call event, bind to a frozen A1 task ID, retain ascending event sequence numbers, and agree with the canonical evaluation status. A reference-policy trace is rejected.

The normalized event projection retains sequence, event type, action/evidence IDs, method, hashed route, identity reference, outcome, usage, and duration. The private per-run record counts actions, HTTP requests, model calls, completed-call tokens and costs, route/identity diversity, duplicate requests, repeated unchanged responses, evidence artifacts and citations, invalid citations, findings, validator outcomes, and termination. Missing evidence-level object counts and first relevant observation stay unknown. Usage is unknown when started model calls lack matching completion records. No model intent is inferred.

The aggregate report preserves per-seed/variant cells and rejects comparisons across different budget hashes, protocol versions, source commits, visibility contracts, evaluation versions, or tool schemas. Vulnerable root success is derived only from a scored canonical evaluation and the private A1 oracle; patched recall stays undefined, while rejected submissions are counted. Without an independent oracle export, the report remains explicitly unqualified. With no retained model runs, it emits `not_executed` and no scores. The three development seeds are too few for ranking claims.
